# Database Scripts
You can use any method you want to create your SQLite database file! There are many, many ways to create SQLite database files and most programming languages support this functionality.

The database file for [_A Case of Stolen Candy_](https://steamcommunity.com/sharedfiles/filedetails/?id=3807683717) was created by running the python script [halloween.py](/Scripts/halloween.py). This script is a bit messy, but  feel free to use it as a starting point or use something else entirely!
